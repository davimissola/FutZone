## Sobre o Projeto

O Futzone é uma plataforma de futebol desenvolvida para facilitar o acompanhamento de partidas, times e competições.

A aplicação apresenta os jogos do dia e uma tabela de classificação com os times e suas respectivas pontuações. Além disso, conta com uma página de busca para encontrar jogadores de futebol.

O projeto está sendo desenvolvido com foco no aprendizado e na prática de conceitos do React, TypeScript, consumo de APIs e construção de interfaces modernas e responsivas.

### Funcionalidades

- **Jogos do dia:** visualização das partidas de futebol que acontecem no dia.
- **Tabela de classificação:** acompanhamento dos times, pontos e posições na tabela.
- **Busca de jogadores:** pesquisa de jogadores de futebol.
- **Interface responsiva:** adaptação da aplicação para diferentes tamanhos de tela.
